# Security policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**.
Do not open a public issue for security problems.

## What to include

A description, steps to reproduce, and the affected version or commit.

## Scope notes

JudgeCheck uses no API keys or paid services; the judge model runs locally.
If you find a committed secret, report it privately in the same way.
